# textbook — 学んだ内容を教科書にする

引数は任意（トピックのヒント）。無ければこの会話で学んだ内容から決める。

1. この会話で学んだ内容を拾い、次を提案する。まだファイルは作らない。
   - トピック（タイトル）の候補を2〜3個。それぞれ1行の説明つき。推奨を1つ示す。
   - 章立て（1章 = 1ファイル）。各章に1行の要約。
2. 過去のトピックと照らし合わせる。`~/projects/h5notebook/textbooks/*/README.md` のタイトルと目次を読み、重複する章・内容があれば「どのトピックのどの章と重なるか」を具体的に指摘する。新しく作るか、既存のトピックに章を足すかを選んでもらう。重複が無ければ「重複なし」と1行で書く。
3. ユーザーに確認する（トピック・章立て・重複の扱い）。OK が出るまでファイルを作らない。修正があれば 1 からやり直す。
4. OK が出たら `~/projects/h5notebook/textbooks/<トピック>/` を作り、次を書く。既存トピックに足す場合は、その Dir に章ファイルを足して README の目次を更新する。
   - `README.md`：`# <トピック>`、`目的：<1〜2行>`、目次（各章へのリンクと1行要約）、前提（OS など）。
   - `NN-<kebab-case>.md`：章ごとに1ファイル。会話で出た説明・例・コード・表を、教科書として読める文章に直す。会話で訂正した内容は訂正後の内容で書く。章同士は相対リンクで参照する。
5. 作ったファイルのリンクを出す。ローカルの絶対パス（README と各章）を一覧で示し、ユーザーがそのまま開いて確認できるようにする。コミットはしない（するならユーザーに聞く）。
