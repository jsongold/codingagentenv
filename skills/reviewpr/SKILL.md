# reviewpr — PR レビューのセッションのルール

レビューをどのセッションで行うかのルールは、ここだけに書く。

## ルール
1. レビューは、新規セッションか、`/clear` した review 専用セッションで行う。
2. 同じ PR の再レビューは、初回と同じセッションで行う（`/clear` しない）。

## レビュー用のセッションでの扱い
ほかの決まりと食い違うところは、レビュー用のセッションではこちらを優先する。
- `/pickup` をしない。SessionStart hook が表示する handoff は読み飛ばし、文脈に数えない。
- レビューはこのセッション自身が行う。「main セッションはレビューを Subagent に出す」の例外とする。

## 手順
今のセッションがどれに当たるかを判定し、当てはまる行のとおりにする。

| 今のセッション | すること |
|---|---|
| 文脈が空（新規、または `/clear` の直後。hook が表示した handoff だけがある場合を含む） | 初回レビューとして、PR をレビューする |
| このセッションで同じ PR をすでにレビューしている | 再レビューする。前回の指摘が直ったかを先に確認する |
| それ以外（この PR の実装や、別の作業の文脈が残っている） | レビューせずに止める。新規セッションか、`/clear` した review 専用セッションで `/reviewpr <PR 番号>` を実行するよう伝える |
