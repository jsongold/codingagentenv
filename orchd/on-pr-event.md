無視するもの：
- `_Generated by [Claude Code]` を含むコメントのイベント（自分が書いたもの）
- 自分の push の通知
CCO と owner は同じ GitHub アカウント（`jsongold`）。署名の有無で見分ける。他のアカウント（Codex bot など）のコメントは owner の返答ではない。

状態を読む（読むだけ）：
- `state`, `next`：PR head の commit の trailer。`git log -1 --format='%(trailers:key=State,valueonly)' <head>`（`Next` も同じ）。無ければ空
- `blocked`：`Blocked-On: owner` で始まるコメントがあり、その後に署名の無いコメントが無ければ true
- `blocked`：`Blocked-On: owner` で始まるコメントがあり、その後に owner の返答が無ければ true
- `owner_reply`：最新の `Blocked-On: owner` コメントの後に `jsongold` が書いた、`_Generated by [Claude Code]` を含まないコメントの本文。ただし PR head の commit の committer date より新しいものだけ（返答の後に push 済みなら処理済みで、通常のレビュー・CI・merge の規則に戻る）
次の一手（1 つだけ）：
- `blocked=true`：何もしない
- CI 失敗・レビュー指摘あり：直して push し、その turn でレビューを依頼する（push する commit は `State: review-wait`。未完成のものを push するときだけ `State: working`）
- owner の返答あり：返答に沿って直して push し、レビューを依頼する
- 指摘なし・CI green：wake.md の「merge してよい条件」を確かめる。すべて満たすなら merge して購読を解除する
- owner の判断が要る：PR に `Blocked-On: owner` から始まるコメントを書いて止まる。2 行目以降に質問を書き、末尾に `_Generated by [Claude Code]` を付ける

push の通知そのものでは進まない。レビュー・CI の結果のイベントで進む。
