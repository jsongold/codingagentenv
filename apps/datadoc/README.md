# datadoc

TSV ファイルを Markdown または HTML の表に変換するコマンド。

## 使い方

```sh
datadoc a.tsv b.tsv --md|--html [-o out]
```

- `--md` か `--html` のどちらか 1 つが必須
- `-` を渡すと stdin から読む（1 回まで）
- `-o` があればそのファイルに書く。無ければ stdout
- 複数ファイルのときは、ファイル名の見出し（`## name` / `<h2>`）で区切る

## TSV の形式

- 1 行目がヘッダ
- 全行が同じ列数
- セル内の タブ・改行・`\` は `\t` `\n` `\\` とエスケープする
- 引用符は使わない
- UTF-8、改行は LF
